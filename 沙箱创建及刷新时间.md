## 创建沙箱实例
### 功能描述
根据沙箱服务的模板 id 创建实例
### URI
- 请求方式：POST
- 接口地址：https://{APIG-Endpoint}/livefunction/sandboxes
### 请求参数
1、header
- X-HW-ID:字符串，应用 id
- x-HW-APPKEY:字符串，APIG 网关应用 密钥

2、body

| 参数          | 是否必填 | 参数类型            | 描述                 |
| ------------- | -------- | ------------------- | -------------------- |
| templateId    | 是       | string              | 沙箱模板 id          |
| timeout       | 否       | integer             | 沙箱实例的生命周期   |
| envVars       | 否       | Map<String,String>  | 沙箱环境变量         |
| metadata      | 否       | Map<String,String>  | 业务自定义字段       |
| X-mounts      | 否       | Array\<Object\> （元素结构如下） | 用户空间绑定相关参数 |
| - workspaceId | 是       | string              | 用户空间 id          |
| - subpath     | 否       | string              | 用户空间挂载路径     |
| - readOnly    | 否       | boolean             | 是否只读             |
| - mountPath   | 否       | string              | 沙箱实例挂载路径     |

### 响应参数

| 参数    | 参数类型 | 描述 |
| ------- | -------- | ---- |
| code    | integer  |      |
| message | string   |      |
| data    | Object   |      |

响应 data 参数

| 参数         | 参数类型 | 描述                                              |
| ------------ | -------- | ------------------------------------------------- |
| sandboxId    | string   | 沙箱实例 ID                                       |
| templateId   | string   | 沙箱服务 id                                       |
| timeout      | integer  | 超时时间                                          |
| cpu          | integer  | cpu 大小                                          |
| memory       | integer  | 内存大小                                          |
| status       | string   | 沙箱实例状态（starting、running、stopped、error） |
| startAt      | string   | 实例开始运行时间                                  |
| readyTime    | integer  | 实例拉起耗时，毫秒                                |
| createClient | string   | 创建客户端节点 ip                                 |
| x-mounts     | Array\<Object\> | 用户空间绑定参数                                  |

## 刷新沙箱实例

### 功能描述

根据沙箱实例 id 刷新沙箱存活时间

### URI

- 请求方式：POST
- 接口地址：https://{APIG-Endpoint}/livefunction/sandboxes/refresh/{sandboxId}

### 请求参数

1、header

- X-HW-ID:字符串，应用 id
- x-HW-APPKEY:字符串，APIG 网关应用 密钥

2、路径参数

| 参数      | 是否必填 | 类型   | 描述        |
| --------- | -------- | ------ | ----------- |
| sandboxId | 是       | string | 沙箱实例 id |

3、body 参数

| 参数     | 是否必填 | 类型    | 描述                       |
| -------- | -------- | ------- | -------------------------- |
| duration | 是       | integer | 沙箱存活时间，硬上限 1800s |

### 响应参数

| 参数    | 参数类型 | 描述 |
| ------- | -------- | ---- |
| code    | integer  |      |
| message | string   |      |
